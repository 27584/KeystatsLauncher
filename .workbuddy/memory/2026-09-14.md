## 修复：看板 SVG 图表被横向拉伸（圆点变椭圆）

**症状**（主人截图指出「这个傻逼缩放」）：`web/` 看板的折线/柱状图里，数据点圆点变成扁椭圆，
坐标标签与图例文字被横向拉宽发虚，竖直线段比水平线段粗近一倍。

**根因**（`web/app.js`）：
- 三个渲染函数 `renderLine` / `renderBars` / `renderRate` 把 `viewBox` 写死成 `560×200`，
  同时 SVG 用 `width="100%" height="100%"` + `preserveAspectRatio="none"`；
- 而容器 `.chart { height: 240px }`（见 `web/style.css:180`）是固定高度、宽度随窗口变化，
  宽屏下容器宽高比 ≈ 4.6，与 viewBox 的 2.8 严重不符 → 横纵缩放系数不等，整张图被横向拉扁。
- 实测拉宽倍率：**2.5:1**（1440 视口下）。

**修法**：让 `viewBox` 直接取容器内容区的 CSS 像素尺寸，做到 1 用户单位 = 1 CSS px，横纵系数恒等。
- 新增 `chartSize(el)`：`getBoundingClientRect()` 减去 `padding`，得到内容区尺寸；
- 三个渲染函数改用实测 `W/H`，视图盒子与容器严格同比例，`preserveAspectRatio="none"` 全部移除；
- 新增 `autoRedraw(el, fn)` / `stopRedraw(el)`：用 `ResizeObserver` 在容器尺寸变化时重绘
  （窗口缩放、`@media (max-width:760px)` 时 `.chart-grid` 从两列变一列），
  以「实测尺寸与记录不同」为门槛防止重绘自激循环；无数据时 `stopRedraw` 掉，避免重绘残留。

**验证**（不是靠肉眼）：用 Edge `--headless=new --screenshot` 渲染真实 `web/app.js`
（Supabase 打桩喂假数据），再用 PIL 量像素：
- 数据点宽高比 **2.50 : 1 → 0.83 : 1**（正圆）；
- 平直段纯线条垂直粗细 **1 px → 2 px**（与 `stroke-width="2"` 一致）。

**产物**：
- `screenshots/chart-scaling-fix.png`、`screenshots/chart-dots-fix.png`（修复前后对照）
- `web/app.js` 与 `docs/app.js` 已同步为同一份（md5 `97e7f61eaf42`）

**踩坑**：
- 验证页少写 `#deviceList`，`loadDevices()` 抛错且其 catch 里又对 null 取属性，
  整条 `loadDevices().then(loadDashboard)` 静默断链，图表区全空 —— 排查了 3 轮才定位。
- Edge 的 `--user-data-dir` 不能放在项目目录里：跑完会锁目录，

  现在 profile 一律落在 `%TEMP%`。

## 修复：柱状图柱心整体右移一个柱宽

**症状**（主人指出「鼠标点击量的柱状图水平位置不对」）：`鼠标点击量` 卡片的柱子与下方日期刻度对不齐，
整体右偏；最后一根柱子还顶出绘图区右边界。

**根因**（`web/app.js` `renderBars`）：柱子的左边界算成了 `PL + i*slot + (slot + barW)/2`。
槽 i 占据 `[PL + i*slot, PL + (i+1)*slot]`，柱宽 `barW` 时左边界应为 `PL + i*slot + (slot - barW)/2` ——
符号写反，等于把每根柱子**右推了整整一个柱宽**。同一函数里的刻度标签（`slot/2`）与
`bindChartHover.xOf`（`slot/2`）都用的是槽中心，所以只有柱子错位，刻度和悬停点是对的。

**验证**（Edge 无头渲染 + 像素测量，1440 视口，14 根柱）：
- 修复前：14 根柱心相对槽心**全部偏 +16.2 px**（理论柱宽 16.78），首柱左间隙 23 px（应 6.5），
  末柱右间隙 **-9 px**（即溢出右边界）；
- 修复后：柱心误差 **-0.8 ~ -0.2 px**（亚像素），左右间隙 7 / 8 px，两侧对称。

**产物**：`screenshots/chart-bars-fix.png`（含「应有的槽中心」红线辅助线）；
`web/app.js` 与 `docs/app.js` 同步（md5 `69abc029309e`）。

**判据沉淀**：柱状图的正确性检查 = `首柱左间隙 == 末柱右间隙 == (slot - barW)/2`，
且每根柱心 == `PL + (i+0.5)*slot`。测灰基线不可行（`--line` 1px 半透明渲染后落在容差外），
改用「卡片白色区域 ± CSS padding」反推绘图区更稳。
